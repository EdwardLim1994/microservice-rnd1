# Test Data Strategy — KAN-5 (Monthly Automated Payroll Generation)

| Data state | Store | Source |
|---|---|---|
| Employee with no unpaid leave this month (full pay) | PostgreSQL (`payroll-infra`) + gRPC stub to `leave-grpc` | fixture + stubbed `GetUnpaidLeaveDays` returning 0 |
| Employee with unpaid leave days this month (deduction case) | same | fixture + stubbed `GetUnpaidLeaveDays` returning N |
| Payroll already generated for the month (idempotency test) | PostgreSQL | fixture: `payroll-record-existing.sql` |
| MinIO test bucket | MinIO (services/minio) | ephemeral bucket per test run, torn down after |
| Rendered PDF sample (for download/content assertions) | MinIO | generated by the code under test, not hand-authored |
| `payroll.generated` Kafka event | Kafka (via Debezium CDC) | generated by fixture inserts through the real CDC pipeline |
